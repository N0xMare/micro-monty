# Benchmark evidence

The measurement harnesses and their results that used to live here moved,
at the same paths, to the `evidence` branch of the private archive
`N0xMare/micro-monty-archive`. Every file is also in micro-monty's public
history: `git show da1c21b5:bench/evidence/<path>` (or browse the tree at
`da1c21b5`).

What stays is what `hosts/js/bench` reads: the 22 code-mode tasks' recorded
tool fixtures (`engines/fixtures/`), their JavaScript solutions
(`engines/js/`) and the checker of a run's tool calls (`engines/check.py`).
