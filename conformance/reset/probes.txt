# Reset probes (README.md here). Each probe is a cell A, a `reset()` and a
# cell B: B must report what it reports in a new session with the same host
# definitions (its value or error, its output and its host calls).
#
#   === label          B after A and a reset equals B in a new session
#   !== label          a documented difference: B must differ
#   >>> Type: message  what A must end in (CPython's error for a refusal)
#   ---                ends A, starts B
#   @walk mark|check   walk.py with that MODE
